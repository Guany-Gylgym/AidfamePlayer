# Security reporting

Do not disclose credentials, private footage or weaponized media in public
issues. If GitHub private vulnerability reporting is enabled, use the Security
tab to report privately. Otherwise open a minimal issue requesting a private
channel, without exploit details or sensitive files.

Include affected revision, platform, impact and safe reproduction details.
There is no guaranteed response time. No public binary security certification
is claimed. Local playback still processes untrusted media; keep dependencies
maintained and preserve local-file, DLL-search and cache ownership checks.
