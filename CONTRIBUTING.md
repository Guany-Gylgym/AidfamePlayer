# Contributing

Keep changes focused and preserve offline operation. Do not add analytics,
network playback or automatic updates without an explicit design decision.

Report revision, Windows version, GPU/driver, codec profile, reproduction steps,
expected and actual behavior. Redact personal paths. Prefer generated media;
never upload private footage or credentials.

Build and run relevant Qt tests. UI changes need native Windows screenshots at
appropriate DPI settings; playback changes need real runtime checks. Missing
hardware coverage is not a pass.

Contributions must be your own work or supplied with compatible permission and
provenance. By submitting project-owned changes, you offer them under the same
GPL-3.0-or-later license. Keep third-party attribution intact. No response-time
or feature-delivery commitment is made.
