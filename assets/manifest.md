# Asset Manifest

All SVG assets are authored for this project and embedded through Qt resources.

- icons/brand-dev.svg: 96x96 viewBox, transparent interim development mark. NOT the final user-supplied artwork.
- icons/play.svg, volume.svg, camera.svg, record.svg, fullscreen.svg: 24x24 viewBox, rendered at 20 logical pixels.
- icons/brand.png: AI-generated replacement artwork authorized by the owner; see brand-prompt.md.
- icons/AidfamePlayer.ico: multi-resolution Windows icon derived from brand.png.

Colors and sizing are defined in docs/DESIGN.md. Do not crop interface icons from screenshots.
